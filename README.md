# seo-geo-specialist-ru

Claude Code skill: аудит и стратегия продвижения коммерческих сайтов (услуги, товары, B2B) на российском рынке — классическое SEO под Яндекс/Google и GEO/AEO (видимость в Алисе, YandexGPT, ChatGPT, Perplexity, Gemini, AI Overviews).

Учитывает специфику РФ: приоритет Яндекса, требования 152-ФЗ (персональные данные) и 168-ФЗ (обязательный перевод иностранных вставок в интерфейсе), доступные в России инструменты.

## Что внутри

- `SKILL.md` — методология аудита, построения семантического ядра, техзадания копирайтеру, работы с AI-краулерами и структурированной разметкой.
- `references/` — GEO/AEO-специфика, шаблоны JSON-LD, юридические требования (152-ФЗ/168-ФЗ).
- `CHANGELOG.md` — история изменений скилла.
