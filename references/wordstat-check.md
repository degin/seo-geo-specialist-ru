# Проверка частотности Wordstat — scripts/wordstat_check.py

Официальный платный метод Яндекса (Yandex Cloud Search API v2), не парсинг и не серая
зона. Источник реализации и договорённостей по API — сервис [KeyWai](https://github.com/AndreyTsibin/keywai)
(`backend/apps/parsing/services/wordstat.py`), сюда вынесен только нужный минимум: без
Docker/Django/Postgres, чистый Python-скрипт.

## Получение ключа

1. Консоль <https://console.cloud.yandex.ru/> → создать **каталог** (folder).
2. Создать **сервисный аккаунт**, выдать роль **`search-api.webSearch.user`**.
3. Создать для аккаунта **API-ключ**.
4. `cp scripts/.env.example scripts/.env`, заполнить `YANDEX_SEARCH_FOLDER_ID` и
   `YANDEX_SEARCH_API_KEY`.

VPN не нужен — сервис доступен из РФ напрямую.

## Стоимость

- `topRequests` (частотность + связанные фразы) — ~20 ₽ за 1000 запросов.
- `getRegionsTree` (список регионов) — бесплатно.
- Скрипт не кеширует — каждый повторный запрос той же фразы снова платный. Для
  разовых/точечных проверок в рамках аудита это не критично; при регулярном сборе
  большого ядра — кешируй результаты руками (например, сохраняй JSON-вывод в файл).

## Использование

```bash
# частотность фразы, вся Россия, все устройства
python scripts/wordstat_check.py "купить телефон"

# конкретные регионы (213 = Москва, 1 = Москва и область — см. --regions-tree) и устройства
python scripts/wordstat_check.py "купить телефон" --regions 213,1 --devices desktop,mobile

# список регионов, чтобы найти нужный ID (бесплатно)
python scripts/wordstat_check.py --regions-tree

# машиночитаемый JSON — для передачи дальше в обработку
python scripts/wordstat_check.py "купить телефон" --json
```

Требуется пакет `requests` (`pip install requests`, если ещё не стоит).

## Ограничения

- Нет `negative_prompt`-аналога — метод просто отдаёт данные, фильтрация фраз (мусор,
  нерелевантные интенты) — на стороне того, кто анализирует вывод.
- `numPhrases` — максимум 2000 за один вызов.
- Rate limit и ошибки 401/403/429 — скрипт останавливается с понятным сообщением,
  повторные попытки не встроены (для точечных проверок это не нужно).
